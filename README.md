# Nihongo 10 JP — Final

Статический интерактивный курс японского языка N5–N1.

## Публикация на GitHub Pages
1. Загрузите все файлы этого архива в корень репозитория.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main / root.
5. Сохраните и откройте выданный GitHub Pages адрес.

## Важно
Озвучка использует SpeechSynthesis браузера. Японский голос зависит от Android/браузера.
Прогресс и фотографии хранятся локально в браузере.
