Nihongo 10 — FINAL

Абсолютный ноль → N5 → N4 → N3 → N2 → N1.
10 минут — рекомендация, таймера нет.
Обучение: кана и произношение → слова → простые фразы → грамматика и чтение постепенно → аудирование → диалоги → письмо → повторение → контрольные.

Методические ориентиры: общие принципы Genki и Minna no Nihongo (постепенность, sentence patterns, контролируемая практика, диалоги, listening/reading/writing), а также навыки JLPT. Защищённые тексты и упражнения учебников не копируются.

Озвучка: Web Speech API, японский язык ja-JP. Если на устройстве нет японского системного голоса, его нужно установить в настройках ОС/браузера.
