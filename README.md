# Nihongo 10 JP — Final

Статический интерактивный курс японского языка N5–N1.

## Публикация на GitHub Pages
1. Распакуйте архив.
2. Загрузите **все файлы из архива** в корень репозитория GitHub.
3. Если GitHub спросит про замену `index.html` или `hero-bg.png`, подтверждайте замену.
4. GitHub → Settings → Pages → Deploy from a branch → `main` / `root`.
5. Откройте адрес GitHub Pages после завершения deployment.

## Что исправлено в этой версии
- Главная использует только новый фон `hero-bg.png`; старого `hero-japan.png` в архиве нет.
- В словаре у каждого слова есть японское чтение и ромадзи.
- Кнопки 🔊 используют японскую озвучку браузера и выбирают доступный голос `ja-JP`, когда он установлен.
- Для слов озвучивается именно поле чтения, поэтому кандзи не мешают правильному произношению.
- Прогресс и фотографии хранятся локально в браузере.

### Если звука нет
На Windows/Android браузер должен иметь установленный японский голос. После его установки полностью обновите страницу. В Chrome можно проверить системные языки и преобразование текста в речь в настройках ОС.
